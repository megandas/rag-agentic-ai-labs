# 💗 1. Document Loaders

Document loaders import external data into LangChain.

| Loader | Loads |
|--------|-------|
| `TextLoader` | `.txt` documents |
| `PyPDFLoader` | PDF documents |
| `WebBaseLoader` | Web pages |

### Example

```python
loader = TextLoader("companyPolicies.txt")
documents = loader.load()
```

### Output

Each document contains:

- `page_content` → Actual text.
- `metadata` → Source information.

# 💜 2. CharacterTextSplitter (Chunking)

### Why Chunking?

LLMs have limited context windows, so long documents must be divided into smaller chunks.

### Example

```python
text_splitter = CharacterTextSplitter(
    chunk_size=300,
    chunk_overlap=50
)

chunks = text_splitter.split_documents(documents)
```

### Parameters

| Parameter | Meaning |
|-----------|---------|
| `chunk_size` | Maximum characters in one chunk. |
| `chunk_overlap` | Shared characters between adjacent chunks. |

### Visualization

```text
Large Document
────────────────────────────────────────

Chunk 1
        Chunk 2
                Chunk 3
                        Chunk 4
                                Chunk 5
```

### Why Overlap?

Prevents important information from being split across chunks.

# 💙 3. Embeddings

### Definition

Embeddings convert text into numerical vectors representing semantic meaning.

### Model Used

```python
HuggingFaceEmbeddings(
    model_name="sentence-transformers/all-MiniLM-L6-v2"
)
```

### Example

| Sentence | Result |
|----------|--------|
| Mobile reimbursement policy | Vector |
| Phone expense refund | Similar vector |

### Why Embeddings Instead of Keyword Search?

| Keyword Search | Embedding Search |
|----------------|------------------|
| Matches exact words. | Matches meaning. |
| Misses synonyms. | Finds semantically similar text. |

**Exam Keyword:** Semantic Search.

---

# 💛 4. Chroma Vector Database

### Purpose

Stores embeddings and performs similarity search.

### Example

```python
vectorstore = Chroma.from_documents(
    documents=chunks,
    embedding=embeddings
)
```

### Retriever

```python
retriever = vectorstore.as_retriever(
    search_kwargs={"k":3}
)
```

Returns the **Top-K** most relevant chunks.

# 🩵 6. RetrievalQA Chain

### Purpose

Connect Retriever + LLM.

### Example

```python
qa = RetrievalQA.from_chain_type(
    llm=llm,
    chain_type="stuff",
    retriever=vectorstore.as_retriever()
)
```

### Workflow

```text
Question
   │
Retriever
   │
Relevant Chunks
   │
Stuff Chain
   │
LLM
   │
Answer
```

### `chain_type="stuff"`

- Combines retrieved chunks into one prompt.
- Sends the entire context to the LLM.

# 🩷 7. PromptTemplate for RAG

### Purpose

Controls LLM behavior and reduces hallucinations.

### Example

```python
prompt_template = """
Use the information from the document.

If you don't know the answer,
say that you don't know.

Do not make up an answer.

{context}

Question: {question}
"""
```

### Why Important?

- Grounds answers in retrieved documents.
- Prevents fabricated responses.

# 💜 9. ConversationalRetrievalChain (Memory)

### Purpose

Allows chatbot to remember previous questions.

### Example

```python
memory = ConversationBufferMemory(
    memory_key="chat_history",
    return_messages=True
)

qa = ConversationalRetrievalChain.from_llm(
    llm=llm,
    retriever=vectorstore.as_retriever(),
    memory=memory
)
```

### Conversation Flow

```text
Question 1
      │
Answer Stored
      │
Question 2 ("List the points in it.")
      │
Memory understands "it"
      │
Context + History
      │
Answer
```

### Why Memory?

Without memory:

> "List the points in it."

Model doesn't know what **it** means.

With memory:

Model knows **it = Mobile Policy**.
