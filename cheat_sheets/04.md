# 🌸 1. What is Gradio?

**Gradio** is an **open-source Python library** used to create interactive **web-based interfaces** for Python functions, machine learning models, and AI applications.

Instead of interacting with a model through the terminal, Gradio creates a webpage where users can provide inputs and receive outputs.

### Why use Gradio?

- No frontend development required.
- Converts Python functions into web apps.
- Supports text, images, audio, video, and file uploads.
- Perfect for AI demos and chatbots.

# 💙 3. Core Gradio Components

| Component | Purpose |
|-----------|---------|
| `gr.Interface()` | Creates a web interface for a function. |
| `gr.Textbox()` | Text input/output field. |
| `gr.Number()` | Numeric input/output field. |
| `gr.Image()` | Image upload/input. |
| `gr.File()` | Upload one or multiple files. |
| `launch()` | Starts the Gradio application. |

### Simple Example

```python
import gradio as gr

def greet(name):
    return f"Hello {name}!"

app = gr.Interface(
    fn=greet,
    inputs=gr.Textbox(label="Name"),
    outputs=gr.Textbox(label="Greeting")
)

app.launch()
```

# 💚 4. Multiple Inputs in Gradio

Gradio accepts multiple inputs as a list.

```python
def info(name, age):
    return f"{name} is {age} years old."

gr.Interface(
    fn=info,
    inputs=[
        gr.Textbox(label="Name"),
        gr.Number(label="Age")
    ],
    outputs=gr.Textbox()
).launch()
```

### Output

- Textbox for name.
- Number field for age.
- Returns combined output.

# 🩷 5. File Upload with Gradio

`gr.File()` allows users to upload files through the web interface.

### Example

```python
def count_files(files):
    return len(files)

gr.Interface(
    fn=count_files,
    inputs=gr.File(file_count="multiple"),
    outputs=gr.Number()
).launch()
```

### Supports

- PDFs
- Images
- CSVs
- Multiple files

# 💛 6. Image Captioning with BLIP

### What is Image Captioning?

Image captioning automatically generates a natural language description of an uploaded image.

### Model Used

**BLIP (Bootstrapping Language-Image Pretraining)**

BLIP understands both images and text.

### Workflow

```text
Upload Image
      │
      ▼
BLIP Model
      │
      ▼
Generated Caption
      │
      ▼
Gradio Output
```

### Example

| Uploaded Image | Caption |
|----------------|---------|
| Dog playing in a park | "A brown dog running in a grassy park." |
| Cat sleeping on sofa | "A gray cat sleeping on a couch." |

### Why Use It?

- Accessibility for visually impaired users.
- Photo organization.
- Digital asset management.
- Automatic image descriptions.

# 🧡 7. Building a Q&A Chatbot (LLM + Gradio)

### Goal

Create a chatbot where users ask questions through a webpage and receive LLM-generated answers.

### IBM Version

- Llama / Mixtral models.
- Watsonx.ai API.
- Gradio frontend.

### Google Colab Version

- Qwen2.5-0.5B-Instruct.
- Hugging Face Transformers.
- No API keys.

### Workflow

```text
User Question
      │
      ▼
Textbox Input
      │
      ▼
generate_response()
      │
      ▼
LLM (Qwen)
      │
      ▼
Textbox Output
```

### Main Function

```python
def generate_response(prompt_txt):
    response = chatbot(prompt_txt)[0]["generated_text"]
    return response
```

# ❤️ 8. Important LLM Parameters

| Parameter | Purpose |
|-----------|---------|
| `temperature` | Controls creativity/randomness. |
| `max_new_tokens` | Maximum response length. |
| `do_sample` | Enables sampling/random generation. |
| `return_full_text=False` | Returns only generated answer, not the prompt. |

### Increase Response Length

```python
max_new_tokens = 512
```

Longer answers for chatbot responses.

# 💙 11. PDF Loader

### Purpose

Reads uploaded PDF into LangChain document objects.

```python
loader = PyPDFLoader(file_path)
documents = loader.load()
```

### Output

Each page becomes a `Document` containing:

- `page_content`
- `metadata`

---

# 💚 12. RecursiveCharacterTextSplitter

### Purpose

Splits large PDF into manageable chunks.

```python
RecursiveCharacterTextSplitter(
    chunk_size=1000,
    chunk_overlap=100
)
```

### Why Recursive?

Splits intelligently by:

1. Paragraph
2. Sentence
3. Word

Maintains context better than simple splitting.

---

# 💛 13. Embeddings (MiniLM)

### Purpose

Convert each chunk into a semantic vector.

```python
HuggingFaceEmbeddings(
    model_name="sentence-transformers/all-MiniLM-L6-v2"
)
```

### Why Embeddings?

- Capture meaning.
- Not exact keywords.
- Similar meanings produce similar vectors.

Example:

| Question | Matching Chunk |
|----------|----------------|
| Phone expense refund | Mobile reimbursement policy |

---

# 🧡 14. Chroma Vector Database

### Purpose

Stores embeddings locally.

```python
Chroma.from_documents(

)
```

### Stores

- Embeddings

- Metadata

# ❤️ 15. Retriever

### Purpose

Find the most relevant chunks for a user's question.

```python
retriever = vectorstore.as_retriever(
    search_kwargs={"k":3}
)
```

### Uses

- Cosine similarity.
- Semantic similarity search.
- Returns Top-K chunks.

---

# 💖 16. RetrievalQA Chain

### Purpose

Connect Retriever and LLM.

```python
RetrievalQA.from_chain_type(
    llm=llm,
    chain_type="stuff",
    retriever=retriever
)
```

### `chain_type="stuff"`

Retrieved chunks are combined into one prompt and sent to the LLM.
